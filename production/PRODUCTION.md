# One Workspace — creative and technical plan

Status: music-and-effects visual preview; narration remains a planned dependency, not removed from scope.

Art direction: restrained cyan/violet against ink black; airy editorial ice-white chapters; sculptural logo, tilted instrument-like UI surfaces, and a directional cyan blade connecting scenes. Typography: Manrope with Noto Sans Arabic. Large titles stay inside a 72 px horizontal safe area; critical content stays above the social-platform bottom overlays. Shapes and CSS perspective provide dimensionality without an expensive 3D render engine. Motion blur is selective on converging hook panels; no full-frame multi-sample blur cost.

## Audio

Original deterministic electronic score at 120 BPM, with warm additive pads, restrained pulse, mallet figure, soft percussion and stereo delay. Separate effects stem contains original filtered-noise sweeps, low impacts and UI ticks aligned to edits and mode switches. No samples, commercial stock music or borrowed composition. 48 kHz stereo WAV sources. Cloud full preview is normalized to a -16 LUFS target / -1.5 dBTP ceiling and encoded as 192 kb/s AAC. This is a provisional music/effects mix; the final voice-integrated mix must be reviewed later.

production/narration.json is the narration handoff: approved wording, maximum windows, style direction, and approval flag. Future narration needs to fit these windows with intentional speech-free gaps. When an approved voice file arrives, add it to the main Film timeline, adjust ducking if needed, review timing and intelligibility, and obtain final audio approval. Merely flipping the approval flag is insufficient.

## Verification gates

- TypeScript and exact Remotion version checks before every cloud render.
- Proof mode renders 4 seconds of Battle, 7.5 seconds of Creation and 3 seconds across the Creation/Pricing boundary. Ten full-resolution frames cover all eight scenes and all creative modes.
- Review those outputs before any full-length render. Concurrency is fixed to two Chromium tabs on a standard 4-vCPU public Ubuntu runner.
- Full-preview mode records render time, encodes H.264/AAC, creates a 30-frame filmstrip from the actual MP4 and probes dimensions, codec, fps, frame count, channel count, sample rate and duration.
- No local video renders; local Studio interaction is used for layout checks. Downloading and decoding cloud results for review does not re-render the composition.

## Limitations

Professional narration is missing by explicit user direction. UI demonstrations are enlarged source-based illustrations; no real model calls or performance comparisons were executed. The motion scene uses original vector artwork, not an output generated by Models Suite. No official-partnership inference should be drawn from model names. This is original work inspired by the requested quality direction, not a reproduction of another company's advertisement. Studio-level polish is an artistic judgment and is not claimed as verified.
